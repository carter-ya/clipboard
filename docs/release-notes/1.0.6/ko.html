Clipboard 1.0.6

새로운 기능

  • 시스템 설정 따르기, 라이트, 다크 모드를 선택할 수 있으며 변경 사항이 즉시 적용됩니다.
  • ⌘ 키를 누르고 있거나 포인터를 올리면 유형 필터와 전체/고정 탭의 단축키를 확인할 수 있습니다.
  • AI 설정 아이콘에 부드러운 금빛 반짝임을 추가했습니다. 동작 줄이기 설정을 따르며 창이 숨겨지거나 최소화되거나 완전히 가려지면 애니메이션을 멈춥니다.

개선 사항

  • 기록과 환경설정을 더욱 macOS다운 인터페이스로 개선했습니다. macOS 26 이상에서는 Liquid Glass를, 이전 버전에서는 호환되는 소재를 사용합니다.
  • 다중 디스플레이 배치와 작은 화면의 레이아웃을 개선했습니다. 기록 창은 포인터가 있는 화면에 열리며 환경설정도 기록 창과 같은 화면을 우선 사용합니다.
  • 숨겨진 창의 렌더링 작업을 줄이고, 환경설정을 일시적으로 숨기거나 최소화해도 저장하지 않은 편집 내용을 유지합니다.

수정 사항

  • 단축키로 창을 열거나 환경설정에서 돌아온 뒤 검색창에 초점이 맞지 않는 문제와 검색 안내 문구의 깜박임을 수정했습니다.
  • 설정 페이지를 다시 열 때 외관 선택기의 너비가 달라지는 문제를 수정했습니다.
  • 로그인 시 실행 스위치와 시스템 설정의 상태가 일치하지 않는 문제를 수정했습니다.
  • AI 탭의 글자나 여백을 클릭해도 반응하지 않는 문제를 수정했으며, Control 클릭의 기본 동작을 유지합니다.

다운로드

  • Apple Silicon(arm64) 및 Intel(x86_64)용 개별 다운로드와 SHA-256 파일을 계속 제공합니다. macOS 13 이상이 필요하며 자동 업데이트는 알맞은 아키텍처를 선택합니다.
